### Declaración de uso de IA: Benjamín Urrea
Se utilizo IA (Claude y Gemini, en especifico) para familiarizarme con el funcionamiento de flutter,
ya que, es mi primera vez trabajando con este lenguaje y en especial con el enfoque hacia desarrollo
movíl. El principal uso fue el maquetado general, estructuras como navbar, cuadros de dialogo y otras
estructuras que para mi fueron complemente nuevas. Tambien se utilizo reiteradas veces en la solución
de problemas, tuve muchos problemas tratando de encuadrar cosas con el margen y padding, y cuando no
podia terminar de encontrar la solución por mi y lo que sabía, recurria a la IA. Como ultimo agregado,
me ayudo a poder encontrar una manera de poder acceder de manera nativa a las funciones del dispositivo, 
tales como el GPS o el teclado númerico del telefono para poder marcar un número de emergencias siguiendo
el regalmento establecido para este tipo de aplicaciones.
