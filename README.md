## Asistencia de Inteligencia Artificial en el Desarrollo

Para este desarrollo se utilizó asistencia de IA en diversas etapas del proceso de ingeniería de software. En primer lugar, se aplicó en el proceso de refactorización (RYS), transformando prototipos de código bruto y layouts extensos en widgets de Flutter modulares, limpios y estrictamente alineados con los estándares de diseño del proyecto. Asimismo, se empleó para optimizar la lógica de la interfaz de usuario, facilitando la generación de algoritmos para el manejo de estados dinámicos, la navegación secuencial entre campos de texto (OTP) y la lógica de temporizadores de seguridad. Por último, se integró en las tareas de documentación y anotaciones, permitiendo la creación de comentarios técnicos detallados en el código fuente para mejorar significativamente su legibilidad y facilitar el mantenimiento futuro por parte del equipo.
